# Sistema de Reservas de Canchas de Pádel

## Descripción
Este proyecto consiste en el desarrollo de un sistema de reservas de canchas de pádel, realizado en lenguaje Python para la materia Programación I.
El sistema tiene como objetivo permitir la gestión de reservas de manera organizada, diferenciando las funcionalidades disponibles para clientes y administradores.

## Funcionamiento general

Al iniciar el sistema, el usuario deberá seleccionar el tipo de acceso:
- Cliente
- Administrador

En caso de seleccionar Cliente, podrá iniciar sesión si ya posee una cuenta o registrarse como nuevo usuario. Una vez autenticado, podrá consultar la disponibilidad de las canchas y gestionar sus reservas.
En caso de seleccionar Administrador, deberá ingresar sus credenciales para acceder a las funcionalidades de administración y gestión del sistema.
